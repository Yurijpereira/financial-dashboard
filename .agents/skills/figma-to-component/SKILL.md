# Objetivo

Implementar mudanças visuais com fidelidade ao protótipo e mínimo impacto funcional.

# Fluxo

1. Separar o que é visual do que é regra de negócio.
2. Identificar componentes reutilizáveis e padrões existentes.
3. Implementar layout e tipografia conforme o design.
4. Preservar a lógica existente, salvo pedido explícito para alterá-la.
5. Validar responsividade e consistência visual.

# Regras

- Não mudar comportamento de filtro, formulário ou dados sem necessidade explícita.
- Não quebrar acessibilidade básica.
- Não criar componente novo se a mudança puder ser absorvida com clareza no componente atual.
- Preservar estados de loading, erro e vazio.
